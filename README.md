# Three Way Hen

Three Way Hen — это прототип Android-игры в жанре branching road runner. Игрок управляет курицей, которая автоматически бежит вперёд по сельской дороге. Периодически дорога разделяется на три ветки: левую, центральную и правую. Перед развилкой игрок выбирает направление свайпом или ничего не делает, чтобы бежать прямо.

Проект создан как игровой прототип по ТЗ для бренда Chicken Road.

## Основной смысл игры

Игрок должен пройти уровень до конца, выбирая безопасные и выгодные ветки дороги. Каждая ветка может содержать разные объекты:

- монеты;
- перья;
- препятствия;
- безопасный путь без бонусов.

Перед развилкой над каждой веткой появляются preview-иконки, которые подсказывают, что ждёт игрока на выбранном пути. Это позволяет заранее принять решение: собрать больше наград или выбрать более безопасную дорогу.

У игрока есть 3 жизни. При столкновении с препятствием отнимается одна жизнь. Если жизни заканчиваются, уровень считается проигранным. Если игрок доходит до финиша с хотя бы одной жизнью, уровень считается пройденным.

## Игровая механика

Основные действия игрока:

- свайп влево — выбор левой ветки;
- свайп вправо — выбор правой ветки;
- без свайпа — движение по центральной ветке;
- тап по экрану — прыжок над препятствием.

На дороге встречаются препятствия:

- камни;
- пни;
- поваленные стволы.

Также на уровне можно собирать:

- монеты;
- перья.

Монеты используются как внутриигровая софт-валюта для покупки скинов. Перья учитываются в прогрессе и достижениях.

## Уровни

В игре предусмотрено 40 уровней. Первые уровни проще: меньше скорость, меньше развилок и препятствий. Далее сложность постепенно растёт:

- увеличивается дистанция уровня;
- повышается скорость движения;
- развилки появляются чаще;
- на ветках становится больше препятствий;
- игроку нужно быстрее принимать решения.

## Магазин

В магазине доступны скины курицы. Каждый скин имеет свою стоимость и способность.

Доступные скины:

1. Basic Runner — обычная курица без бонуса.
2. Preview Far — показывает preview следующей развилки заранее.
3. Quick Swipe — увеличивает окно регистрации свайпа перед развилкой.
4. Feather Magnet — притягивает перья рядом с курицей.
5. Auto Jump — автоматически прыгает через низкие препятствия.

Также предусмотрены дополнительные заблокированные ячейки, которые открываются по достижению определённых уровней.

## Достижения

Экран достижений содержит список игровых целей, связанных с прогрессом игрока:

- прохождение уровней;
- сбор монет;
- сбор перьев;
- успешное прохождение развилок;
- использование скинов;
- победы без потери жизней.

Достижения работают офлайн и сохраняются локально.

## Лидерборд

Leaderboard реализован как псевдо-рейтинг без реального онлайна. В списке отображаются боты с заранее заданными именами и очками. Текущий игрок отображается как `You`.

Рейтинг нужен для создания ощущения соревновательности и прогресса внутри игры.

## Настройки

На экране настроек доступны базовые переключатели:

- Music — включение и выключение фоновой музыки;
- Sound Effects — включение и выключение звуковых эффектов.

Настройки сохраняются локально.

## Технологический стек

Проект разработан под Android.

Основной стек:

- Kotlin;
- Android SDK;
- Android Gradle Plugin 8.12.3;
- Gradle Wrapper 8.13;
- XML Layouts;
- Fragment-based navigation;
- Custom View для игрового экрана;
- Canvas API для отрисовки игровой сцены;
- SharedPreferences / локальное хранилище для прогресса, монет, настроек и покупок;
- AppCompat / AndroidX;
- ConstraintLayout.

## Архитектура

Проект построен по классической Android-структуре с разделением экранов по feature-модулям.

Основные части проекта:

- `MainActivity` — основная Activity приложения;
- fragments — отдельные экраны приложения;
- custom game view — игровая логика и отрисовка;
- repository / storage layer — сохранение прогресса, валюты и настроек;
- models — игровые модели уровней, скинов, достижений и лидерборда;
- resources — изображения, цвета, строки, layout-файлы и drawable-ресурсы.

## Safe Area

В проекте учитываются системные зоны экрана. Safe area применяется на всех основных экранах, чтобы элементы интерфейса не перекрывались статус-баром, navigation bar и системными жестами.

Это особенно важно для Android 15+ и устройств с жестовой навигацией.

## Статус проекта

Текущая версия является игровым прототипом. В ней реализована основная логика, структура экранов и базовая механика Three Way Hen.

Проект можно использовать как основу для дальнейшей доработки:

- подключения финальных Figma-ресурсов;

- балансировки уровней;
